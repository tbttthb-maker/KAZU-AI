## قبل التقديم

أكمل بيانات مالك التطبيق واسم المطوّر وبريد الدعم، وافحص الاسم والعلامة والمعرفات. اقتراح ZOLNU ليس شهادة تسجيل علامة أو ضمان توفر اسم متجر/نطاق.
فعّل الخادم وجرب التفاعل بين حسابين واسترجاع الدخول وحذف الحساب والملفات. راجع سياسات RLS فعليًا مستخدمًا حسابين، مع محاولة تعديل وحذف منشور المستخدم الآخر؛ ينبغي رفضها.
انشر سياسة خصوصية وشروط المجتمع وصفحة دعم ورابط حذف حساب متاحًا على الويب مع آلية عمل حقيقية. المسودة المرفقة لم تُنشر. أضف روابطها للتطبيق ولحقول المتجر.
شغّل عملية إشراف ومتابعة البلاغات، وفلترة المحتوى المخالف، وطريقة اتصال بالمطوّر؛ وجود زر بلاغ وحده غير كافٍ لعملية إشراف.
اختبر على iOS وAndroid حقيقيين، الشبكة البطيئة، رفض الوصول للصور، شاشة صغيرة، فيديوهات بترميزات مختلفة، حذف الحساب، الخروج وتبديل الحسابات، وفشل الرفع.
املأ نماذج App Privacy وData Safety بناءً على الخدمة المنشورة فعلًا. بيانات الحساب والبريد واسم المستخدم والنبذة والمنشورات والصور والفيديوهات والتفاعلات والبلاغات تدخل في الوصف. لا تحدد «لا نجمع بيانات» عند تشغيل السيرفر.
أكمل استبيان العمر والتصنيف بناءً على المحتوى وخطة الإشراف. لا تفترض تصنيفًا قبل الإجابات المطلوبة. أضف حساب مراجعة فعّالًا واختبر بياناته قبل تسليمها للمراجع.
أزل الحسابات والفيديو التوضيحي من مواد المتجر النهائية، واستبدل صور المعاينة بلقطات الإصدار الحقيقي. لا تدّع أن التطبيق يملك مستخدمين أو توصيات ذكاء اصطناعي أو رسائل غير موجودة.

## بناء التوقيع

إعداد `.env` المحلي لا يكفي لبناء سحابي. عيّن القيم في بيئة EAS أو أسرار CI المناسبة. رابط Supabase والمفتاح publishable متاحان داخل حزمة العميل بطبيعة التصميم؛ الخدمة محمية بسياسات RLS. مفاتيح الخدمة والتوقيع أسرار خادم/متجر فقط.

```bash
npx eas-cli login
npx eas-cli init
# اختر معرّف مشروع EAS ومعرّف التطبيق الخاص بك، ثم ضع القيم في بيئة البناء:
# EXPO_PUBLIC_SUPABASE_URL
# EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY
# APP_IDENTIFIER
# EAS_PROJECT_ID
npx eas-cli build --platform all --profile production
```

البناء النهائي يرفض غياب هذه القيم كي لا تُبنى نسخة إنتاج في وضع التجربة. هذا فحص إعدادات وليس فحص جاهزية شاملًا. التوقيع يحتاج حساباتك وموافقاتك؛ لا توجد مفاتيح أو شهادات مُنشأة هنا.

```bash
npx eas-cli submit --platform ios --latest
npx eas-cli submit --platform android --latest
```

قد تحتاج أول عملية رفع أندرويد رفع AAB يدويًا في Play Console قبل دعم الرفع عبر API. راجع وثائق EAS الحالية. الرفع إلى TestFlight/App Store Connect لا يساوي إطلاقًا على App Store. أكمل بيانات المتجر ثم أرسل للمراجعة وحدد الإصدار العام من لوحة المتجر.
