# ZOLNU — زولنو، نسخة الآيفون

النسخة 0.3.0، مبنية بـ React Native وExpo SDK 58 وExpo Router. إعداد الإصدار يستهدف iPhone فقط (`supportsTablet: false`). معاينة المتصفح للفحص أثناء التطوير.

## الميزات المنفذة

رئيسية بصور كاملة العرض، منشورات وصور وفيديو قصير، لايكات وتعليقات ومتابعة وحفظ وبحث، شبكة صور بالملف الشخصي، صورة وغلاف وإطارات، حظر وبلاغ وحذف، وصفحة نشاط مشتقة من التفاعلات المحمّلة. المشغّل يدعم الصوت والإيقاف والسحب بين الريلز.

توجد طريقتان مختلفتان تمامًا للشارات:

- شارة المؤسس: نجمة مكافأة مشاركة في حملة الشركة، تبقى بعد انتهاء الحملة أو إزالة اللايك. هذه **ليست إثبات هوية أو توثيقًا أزرق**.
- التوثيق الأزرق: طلب إثبات ملكية ورابط رسمي، يراجعه مسؤول الشركة بصورة مستقلة. يحفظ السيرفر القرار والمراجع، ولا يسمح للمستخدم بإضافة العلامة لنفسه أو بالاعتماد الذاتي لمسؤول الشركة. تغيير الاسم أو اسم المستخدم أو الصورة يوقف العلامة إلى مراجعة جديدة. هذا توثيق داخل ZOLNU فقط؛ لا يمنح أي توثيق على Instagram أو X أو TikTok.

## الحالة الفعلية

البيانات المحلية أمثلة محفوظة على الجهاز، ولا يراها مستخدم آخر. التسجيل العام وطلبات التوثيق الفعلية يحتاجان مشروع Supabase مفعّلًا. لم يتم إنشاء خدمة مستضافة أو حساب شركة حقيقي أو فريق مراجعة في هذه الجلسة. حساب الشركة يُسند على السيرفر فقط إلى المستخدم الذي أكد ملكية البريد المحدد بإعداد المشروع.

الكود مرفوع إلى الفرع `zolnu/iphone` داخل `tbttthb-maker/KAZU-AI`؛ ملفات المشروع ضمن `zolnu/`. الفرع الرئيسي ومشروعه الأصلي محفوظان.

## التشغيل والفحص

```bash
npm ci
npm run ios
npm run typecheck
npm run lint
npm test
npx expo export --platform ios
```

تصدير JavaScript لا ينتج IPA. سير عمل `.github/workflows/build-ipa.yml` يبني التطبيق الأصلي على macOS بواسطة Xcode، يفحص arm64 والحزمة، ثم يرفق `ZOLNU-Sideloadly.ipa`. الملف الناتج غير موقّع حتى يوقّعه Sideloadly بحساب Apple. نجاح البناء لا يعادل اختبار التطبيق على آيفون فعلي أو قبوله في App Store.

## تفعيل السيرفر

1. أنشئ مشروع Supabase خاصًا بك.
2. على قاعدة جديدة نفّذ بالترتيب `supabase/schema.sql` و`supabase/migrations/002_company_profiles.sql` و`supabase/migrations/003_account_verification.sql` مرة واحدة.
3. ضع رابط المشروع والمفتاح العام publishable في `.env` من `.env.example`. لا تضع service role في التطبيق.
4. فعّل تأكيد البريد وإعداد SMTP وحدود الإرسال، وجرّب حسابين حقيقيين قبل الإطلاق.
5. انشر دالة حذف الحساب:

```bash
npx supabase login
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase functions deploy delete-account
```

لبناء متصل بالسيرفر أضف `EXPO_PUBLIC_SUPABASE_URL` و`EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY` إلى أسرار GitHub ثم شغّل البناء من جديد. كلمة مرور قاعدة البيانات وservice role لا يُضافان إلى التطبيق أو GitHub المصدر.

## حدود الإصدار

الرسائل الخاصة والقصص والبث وإشعارات الدفع ومعالجة الفيديو على السيرفر وخوارزمية التوصية غير منفذة. دوائر الرئيسية تعرض آخر المنشورات؛ لا تدّعي أنها قصص تختفي. ليس التطبيق نسخة كاملة من كل خدمات إنستغرام.

الوسائط المنشورة على السيرفر في bucket عام، والحظر يخفي المحتوى من تجربة الحاظر ولا يجعل رابط الملف خاصًا. البلاغات تسجّل للمراجعة ولا يوجد فريق إشراف تلقائي. البحث والعدادات من البيانات المحمّلة: آخر 100 منشور وما يصل إلى 200 ملف و2000 تعليق و10000 تفاعل. يحتاج التوسع pagination وتجميع عدادات ومعالجة وسائط وفحوصًا إضافية.

للنشر العام يلزم تشغيل السيرفر والإشراف والدعم والخصوصية وحذف الحساب، وحساب Apple Developer واختبار أجهزة ثم تقديم App Store. لا يوجد نشر تلقائي أو ادعاء بأن المتجر وافق عليه.
