# ZOLNU — زولنو

تطبيق React Native / Expo Router للأندرويد والآيفون، مع معاينة متصفح من نفس الكود.
النسخة 0.2.0: مشروع أولي يعمل محليًا؛ لم يُنشر ولم يُوقّع للمتاجر.

اقرأ `release/UPGRADE-0.2-AR.md` لتفعيل حساب الشركة ببريد المالك، وصور الغلاف والإطارات، وحملات التوثيق الدائمة، وبناء IPA غير موقّع لـSideloadly على GitHub macOS.

## تشغيل سريع

على الكمبيوتر ثبّت Node.js LTS الذي تدعمه نسخة Expo المستخدمة، ثم افتح هذا المجلد:

```bash
npm ci
npm start
```

امسح رمز QR بتطبيق Expo Go المتوافق مع SDK 58. إذا إصدار Expo Go على جهازك لا يدعم SDK 58، استخدم development build أو نسخة متصفح بدل تغيير المكتبات منفردة.
يشترط اتصال الهاتف والكمبيوتر بنفس الشبكة عند تشغيل LAN.

```bash
npm run web
```

نظام التشغيل الأدنى يعتمد على نسخة React Native/Expo وإعدادات البناء. لم يُختبر المشروع على جهاز آيفون أو أندرويد فعلي في جلسة الإنشاء. لا تعدّل حد نظام iOS إلى إصدار أقدم من الذي تدعمه المكتبات.

## ما الذي يعمل؟

- واجهة عربية داكنة متجاوبة مع الموبايل والتابلت ومعاينة الكمبيوتر.
- منشورات نصية وصور وفيديوهات، وتعليقات ولايكات ومتابعة ومحفوظات.
- صفحة فيديوهات قصيرة بالسحب العمودي، تشغيل/إيقاف وصوت، وإيقاف عند مغادرة الصفحة أو انتقال التطبيق للخلفية.
- بحث في النص والاسم واسم المستخدم والهاشتاغات الموجودة بالمنشورات.
- ملف شخصي قابل للتعديل، عرض منشورات الحساب، حظر وإبلاغ وحذف منشورك.
- بيانات تجريبية محفوظة محليًا بدون إنشاء حساب أو كلمات مرور محلية.
- ربط اختياري بحسابات حقيقية وقاعدة بيانات وتخزين عبر Supabase، مع سياسات وصول RLS ودالة حذف حساب.

في وضع التجربة لا يرى الآخرون منشوراتك. بيانات الحسابات لينا وعمر ونور أمثلة. الأعداد المعروضة ناتجة عن تفاعلات النسخة وليست إحصاءات مستخدمين حقيقيين. الفيديو التوضيحي والرسوم أصلية ومرفقة محليًا.

على الهاتف تُنسخ الوسائط المحلية إلى مجلد التطبيق الدائم. في معاينة المتصفح تُحفظ الصور الصغيرة ضمن بيانات التجربة؛ حدها 3 MiB. روابط الفيديوهات المختارة محليًا مؤقتة وتحتاج إعادة الاختيار بعد إغلاق المتصفح. لا يُنصح باستعمال معاينة المتصفح لحفظ ملفات مهمة.

## تفعيل المستخدمين الحقيقيين

1. أنشئ مشروع Supabase خاصًا بك.
2. نفّذ `supabase/schema.sql` ثم `supabase/migrations/002_company_profiles.sql` مرة واحدة على مشروع جديد، في SQL Editor. لا تنفّذه على قاعدة فيها جداول تحمل نفس الأسماء.
3. انسخ `.env.example` إلى `.env` وضع رابط المشروع والمفتاح العام publishable. لا تضع service role أو كلمة مرور قاعدة البيانات داخل التطبيق.
4. فعّل تحقق البريد، واضبط SMTP وكلمة مرور من 8 أحرف على الأقل ومعدلات إرسال مناسبة من لوحة Supabase. لا يلزم تعطيل التحقق؛ بعد التأكيد يعود المستخدم للتطبيق ويسجّل الدخول.
5. انشر دالة حذف الحساب باستخدام Supabase CLI:

```bash
npx supabase login
npx supabase link --project-ref YOUR_PROJECT_REF
npx supabase functions deploy delete-account
```

الدالة تتحقق من JWT للمستخدم وتستخدم سر `SUPABASE_SERVICE_ROLE_KEY` في بيئة السيرفر فقط. أسرار Supabase الافتراضية تُحقن بدوال المشروع المستضاف؛ تحقق من وجودها. لا تنسخ السر إلى متغير `EXPO_PUBLIC_...`.
جرّب إنشاء حسابين فعليين والتفاعل بينهما وحذف أحدهما قبل أي إطلاق. تأكد أن حذف الحساب يحذف ملفاته وصفوفه التابعة.

## حدود النسخة الحالية

لا تشمل رسائل خاصة أو قصصًا أو بثًا أو إشعارات دفع أو خوارزمية توصية أو تحويل جودة الفيديو. الخلاصة مرتبة زمنيًا. يتم جلب آخر 100 منشور وما يصل إلى 200 ملف و2000 تعليق و10000 تفاعل؛ الأعداد والبحث تعكس البيانات المحملة. يلزم pagination وتجميع العدادات على السيرفر عند التوسع.

الملفات المنشورة في bucket عام ويمكن فتحها برابط مباشر. الحظر يُخفي محتوى الحساب عن المستخدم الحاظر، ولا يحوّل الملف إلى خاص. لا تضف وعد خصوصية يخالف ذلك.
البلاغات مسجلة بجدول reports؛ لا يوجد فريق إشراف أو معالجة تلقائية مفعّلة. يحتاج الإطلاق مشرفًا، فلترة مناسبة، وقناة دعم منشورة. حد الفيديو الزمني يُفحص بالعميل؛ قبل إطلاق واسع أضف تحققًا ومعالجة على السيرفر للوسائط ومدتها. ترميز HEVC وMOV يختلف دعمه بين الأجهزة؛ تجهيز تحويل موحد H.264/AAC مطلوب لتجربة رفع عامة أكثر موثوقية.

## فحص وبناء

```bash
npm run typecheck
npm run lint
npm test
npx expo export --platform all
```

الأمر الأخير يفحص ويصدر حزم JavaScript ووسائط الويب/أندرويد/آيفون؛ لا ينتج APK أو IPA موقّعًا ولا يختبر التشغيل على أجهزة حقيقية.

لنسخة Android APK داخلية:

```bash
npx eas-cli login
npx eas-cli init
npx eas-cli build --platform android --profile preview
```

لنسخة آيفون تجريبية تحتاج إعداد توقيع Apple/Aجهزة مسجلة أو TestFlight بحسب نوع البناء. لا يوجد IPA/APK جاهز داخل هذا الملف المضغوط.

## ملفات مهمة

- `src/Main.tsx`: الواجهات والتنقل.
- `src/useSocial.ts`: التفاعل والحفظ والعمليات.
- `src/backend.ts`: حسابات وبيانات وتخزين Supabase.
- `supabase/schema.sql`: الجداول وسياسات الوصول.
- `supabase/functions/delete-account/index.ts`: حذف الحساب على السيرفر.
- `app.config.ts` و`eas.json`: إعدادات البناء.
- `release/STORE-AR.md`: خطوات التقديم والمعلومات الناقصة.
- `release/PRIVACY-DRAFT-AR.md`: مسودة وصف البيانات لتكييفها قبل النشر.
- `scripts/make_art.py`: إعادة توليد الأعمال الفنية والأيقونات، يتطلب Pillow.

لا تشارك ملف `.env` أو ملفات توقيع المتاجر. معرّف `dev.zolnu.preview` تجريبي ويجب تغييره إلى معرّف تملكه قبل أول إصدار نهائي.

معاينة الويب تستخدم مسارات Expo Router؛ عند استضافتها على خادم ثابت اضبط إعادة المسارات غير الموجودة إلى index.html. ملف المعاينة المستقل يحتوي معالجة للتنقل بدون خادم.
